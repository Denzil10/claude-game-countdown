Claude gets 60, 30, 10, then 5 seconds to make a game

Video: https://youtu.be/97StcCD_oVs

Each run is a fresh Claude Code session (v2.1.331) in an empty folder, recorded with vhs. The prompt is typed, Enter is pressed, and the recording script sends Ctrl+C exactly when the time limit runs out. Nobody typed anything else. The games below are the files exactly as Claude left them, unedited. Times are from the session logs.

Prompt (only the number changes):
You have 60 seconds, starting when I press Enter. Make a game I can play in the browser: one file, index.html, keyboard controls. At 60 seconds I stop you and play whatever is in index.html. Go.

Controls: arrow keys (the 60 s and 30 s games also take WASD/AD). Space restarts after a game over.

Both finished runs said they had not opened the game in a browser to test it. In the video a small script plays each game by pressing the arrow keys (how/play.py); it reads where the falling objects are and never changes the game. One run per time limit, so this is one sample, not a benchmark.
